# Журнал поставщиков — GitHub Pages + Supabase

## 1. Подготовьте базу

1. Создайте проект на Supabase.
2. Откройте **SQL Editor**.
3. Скопируйте туда содержимое файла `supabase-setup.sql` и нажмите **Run**.
4. В **Project Settings → API** скопируйте `Project URL` и `anon public key`.
5. Вставьте их в файл `config.js`.

## 2. Опубликуйте на GitHub

Загрузите все файлы из этой папки в корень репозитория. В GitHub откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем нажмите **Save**.

Через несколько минут появится адрес сайта. Все устройства будут работать с одной базой Supabase.

## Важно

Эта версия открывается без регистрации. Любой человек, получивший ссылку на сайт, сможет просматривать и изменять записи. Не размещайте в журнале банковские реквизиты, пароли и другие секретные данные.
